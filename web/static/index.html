Как пользоваться SNIN Mail

🔑 Вход

Открой snin-mail.v2.site → введи свой адрес npub…@snin-mail.v2.site и пароль. Адрес можно вводить и просто как npub….

📦 Регистрация ящика

«Зарегистрировать ящик» → свой nsec1… + пароль (мин. 6). Ключ остаётся у тебя: мост использует его только для расшифровки твоих писем. С одним ключом — один ящик.

🔄 Забыл пароль

«Забыли пароль?» → адрес + nsec1… + новый пароль. nsec доказывает, что ключ твой: чужим ключом пароль не сбросить.

✉️ Письма

Письмо = событие kind:1301 в Nostr, шифруется NIP-44 и упаковывается в gift wrap (NIP-59). Никто кроме получателя не видит ни текст, ни тему, ни отправителя. Вложения до 5 МБ, до 5 штук.

⚡ Квоты

Ящик: до 500 писем. Отправка: до 100 писем/сутки. Сверх лимита — письмо не пройдёт.

🛡 Безопасность

Вход — только по паролю, сессия на сервере. Чужая cookie не пускает. Сброс пароля — только по владению ключом. Лимит регистраций: 50/час.

🌐 Внешние клиенты

Мост зарегистрирован по NIP-05 (_smtp@snin-mail.v2.site) — совместимые клиенты (nostrmail.org и др.) могут находить и писать на адреса @snin-mail.v2.site.
